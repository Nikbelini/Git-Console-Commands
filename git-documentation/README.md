# **Git Documentation**

Документация по Git: структурированные материалы для понимания того, как система контроля версий устроена и почему работает именно так.

## Зачем эта папка

Большинство справочников по Git — это просто список команд. Здесь подход другой: сначала объясняется, что происходит «под капотом» (индекс, коммиты, ветки, история), а уже потом — какими командами этим управлять. Так команды перестают быть магическими заклинаниями и превращаются в понятные инструменты.

## Что здесь есть

- **Основы** — модель работы Git: рабочая директория, индекс (staging), репозиторий.
- **Команды с пояснениями** — каждая команда описана с точки зрения того,
  какие объекты и ссылки она затрагивает.
- **Ветки и слияния** — как устроены ветки, чем merge отличается от rebase,
  как разрешать конфликты.
- **История изменений** — чтение log, diff, поиск нужного коммита, отмена изменений.
- **Разбор типичных проблем** — «случайно закоммитил не туда», «нужен откат»,
  «конфликт при мердже» и другие частые кейсы.

## Как пользоваться

Читайте по порядку, если изучаете Git с нуля. Если нужен ответ на конкретный вопрос — используйте оглавление и переходите сразу к нужному разделу. К каждой теме прилагаются команды для консоли с комментариями.
