# Руководство по работе с командами Git в консоле (Git-Documentation). Git-Console-Commands

Репозиторий с подборкой полезных команд Git для консоли, структурированной документацией и описанием рабочего процесса (GitFlow). Подходит для быстрого поиска команд, повторения основ и стандартизации работы в команде.  

* **Документация по основным сценариям** - добавление изменений, ветки, коммиты, конфликты, истории изменений  
* **GitFlow** - описание принятого workflow, правила именования веток и коммитов, порядок мёрджа и релизов
* **Шпаргалки по командам** - самые частые и полезные команды с краткими пояснениями и примерами  
* **Примеры рабочих сессий** - пошаговые сценарии (исправления багов, новые фичи, откаты изменений)
